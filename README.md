# Ragnarok CTF — Season I handouts (Training Grounds, weeks 1-3)

Player-facing challenge downloads for the Netenrich CTF League Training Grounds. Each `.zip` is the
handout for one file-based trial; unzip and work it by hand. The live web trials have no download —
they are played at their URL during their week.

This repository contains **only** handouts — no flags, no solutions. Download a trial's zip from the
link the Training Grounds shows for that week.

Learn. Prove. Share.
